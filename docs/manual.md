# 使い方マニュアル

potalk-cli（`ptk`）の使い方をまとめたマニュアルです。インストールは [OS別の導入ガイド](install.md)、オプション・環境変数・ファイル仕様などの一覧は [リファレンス](reference.md) を参照してください。

## 名乗り（名前と絵文字）

`--name 名前`・`--emoji 絵文字` で名乗れます（`ptk`・`join`・`create` のどれでも）。一度付ければ覚えて、次からは付けなくてもその名前になります（保存先は `~/.config/ptk/profile.json`。名前は20文字、絵文字は8文字までで、本家と同じ上限で切り詰められます）。名乗らなければ、最初に「深煎りキリマンジャロ」のようなコーヒーの名前を自動で付けます。

音を鳴らしたくないときは `--no-sound` を付けます。

## 木の芽（成長バッジ）

木の芽は部屋への参加回数・別々の日に使った日数・累積滞在時間で育ちます。🌿は参加3回・累積5分、🌷／🌻は4日・10回・60分、🌲／🌳は14日・20回・180分が条件です。花と木は平均滞在時間が12分未満なら🌷／🌲、12分以上なら🌻／🌳になります。滞在時間は通話中30秒ごとに加算されます。記録は `~/.config/ptk/growth.json` に保存され、ブラウザ版の記録とは別です（`XDG_CONFIG_HOME` を設定している場合はその配下）。

## ロビー（TUI）

`ptk`（または `ptk lobby`）でロビーを TUI 表示します。

- `j`/`k` で移動、Enter で部屋に入る、`/` で絞り込み、`r` で再読み込み、`q` で終了
- `/` の絞り込みは部屋名・話題タグ・いる人の名前が対象です（Enter で確定、Esc で解除。ひらがな／カタカナ、全角／半角は区別しません）
- F12 でボス画面に切り替わります（後述）

## 部屋に入る・作る

```bash
ptk join          # ロビーから番号で選んで部屋に入る
ptk join 'https://potalk.app/#room=…&name=…'   # 招待リンクで入る
ptk join アサ      # 名前の一部で入る（部屋名・話題タグ・いる人の名前。複数合えば番号で選ぶ）
ptk create 部屋名  # 新しい部屋を作って入る（部屋名を省くと「あなたの名前の部屋」）
ptk list          # 通話中の部屋を一覧で出力（--seconds N で待ち時間、既定 15 秒）
```

部屋にいる間は、po-talk と同じくロビーへ在室を告知します（秘密の部屋を作れないようにする po-talk の決まりです）。

## 部屋の画面（TUI）と行表示

TUI の部屋の画面では、参加者（話している人に 🔊）・お知らせ・入力欄が並びます。

- `i` か Enter で入力欄に入り、ひとことを打って Enter で送信（60 文字まで）。入力中は Tab でコマンド補完できます
- `t` でマイクのオン・オフ、`m` で音を消す・戻す、`q` で退出してロビーへ戻ります
- F12 でボス画面（部屋では短時間の Esc 二回でも起動）

`ptk join` の行表示では、文字を打って Enter でひとことを送ります。Tab でコマンドを補完できます。`/mic` でマイクのオン・オフ、`/who` で参加者（話している人に 🔊）、`/mute` で音を消す・戻す、`/cp` でURLをコピー、`/q`（または Ctrl-C）で退出します。

### マイクの注意

入室時、マイクはオフです。オンにしている間だけ録音（SoX の `rec`）が動きます。ブラウザと違ってエコーを消す仕組みが無いので、**ヘッドホンを使ってください**（スピーカーだと相手の声が相手に返ります）。macOS では、初めてオンにしたときにターミナルのマイク使用の許可を求められます。

### マイクテスト

通話前に `ptk --mic-test` を実行すると、既定入力を5秒間測定して RMS（平均的なレベル）・ピークを表示します。録音データはファイルに保存せず、入力が検出され SoX の `play` が使える場合は同じ端末でローカル再生します。通話中の TUI には SoX から CLI へ届いた入力レベルとピークが表示されます。数値の判定は目安で、CLI までの入力レベルしか分かりません。物理マイクの品質や相手までの回線品質は判定できず、テストが良好でも相手側の聞こえを保証するものではありません。

## 部屋内コマンド

入力欄（行表示ならそのまま）に打つコマンドです。TUI では Tab 補完が効きます。

| コマンド | 動作 |
| --- | --- |
| `/help` | コマンド一覧とヘルプを表示 |
| `/tag 新しい話題` | 部屋の話題を変える（`/notag` で消す） |
| `/list` | 部屋にいるまま、ほかの部屋の一覧を見る |
| `/cp`（`/copy`） | 現在の部屋 URL をクリップボードへコピー |
| `/who` | 参加者一覧と番号を確認 |
| `/card` | 自分の名刺を対話形式で編集（次節） |
| `/card <番号>` | 相手の名刺を要求（SNS 外部照会なし） |
| `/card <番号> --verify` | 名刺鍵の応答確認後、X・GitHub・Nostr の証拠を照合 |
| `/hbk <番号>` | 相手をセッション限定でローカルミュート（次節） |
| `/unhbk <番号>` | ローカルミュートを解除 |
| `/mic` | マイクのオン・オフ（TUI では `t`） |
| `/mute` | スピーカーのオン・オフ（TUI では `m`） |
| `/q`（`/quit`） | 退出（TUI では `q`） |
| `/dice [面数]` | ダイスを振る（後述） |
| `/waka`・`/haiku` | 和歌・俳句を一首／一句、部屋に送信（後述） |
| `/seiza [星座]`・`/uranai [星座]`・`/omikuji` | 星座解説・占い・おみくじ（後述） |

### 名刺（/card）

`/card` はひとこと・X/GitHub/note/Instagram/YouTube/Nostr・お礼窓口（OFUSE/Amazon/Zap/Ko-fi/Buy Me a Coffee）・画像 data URL を対話形式で登録します。ID のほか対応するプロフィール URL も入力できます。画像はあらかじめ128×128px以下に縮小し、WebP/JPEG/PNG の data URL にしてください。各項目は空 Enter で維持し、`-` で削除できます。

`/who` で参加者番号を確認し、`/card 2` のように指定するとその相手にだけ名刺を要求します。名刺は要求された相手1人だけに送られます。

名刺の検証の考え方（何が確認できて、何が確認できないか）は [リファレンス](reference.md#名刺cardと本人確認) にまとめています。要点だけ：**名刺本文には署名がなく、ひとこと・SNS ID・お礼窓口は本人申告のまま**です。通常の `/card <番号>` は SNS へ照会しません。証拠も照合したい場合だけ `/card <番号> --verify` を使ってください（X/GitHub への照会では接続元 IP が伝わる場合があります）。

### ローカルミュート（/hbk）

`/who` の参加者番号を使い、`/hbk <番号>` で相手をローカルミュート、`/unhbk <番号>` で解除できます（自分は1番）。対象は表示名ではなく、その接続の `peerId` です。

ミュートした相手のチャットは画面表示・`--events-jsonl`・`--tts` のいずれにも流れず、音声は再生中のトラックを切り離し、新しいトラックも再生しません。解除すると保持している最新トラックを再接続します。入退室などの通知は通常どおり残り、ミュート状態を相手へ通知しません。状態は退出時に破棄されます。これは通信を止めるブロック機能ではなく、この端末で表示・再生しないための機能です。

### 遊びコマンド

- `/dice` は6面、`/dice 20` は20面のダイスを振り、出目を自分の発言として部屋に送信します。面数は1以上の整数を指定してください。`--tts` を設定している場合は自端末でも読み上げ、受信側では通常の受信コメントとして既存の TTS 経路に渡ります。送信側の `--events-jsonl` には自分の出目は混ざりません。
- `/waka` は国文学研究資料館が CC BY 4.0 で公開する嘉禄二年本『古今和歌集』TEI/XML から一首を、`/haiku` は松山市の CC BY データ「正岡子規の俳句（季節別）」から一句をランダムに選び、作者と短い出典表示を添えて部屋に送信します。古典本文は一行に整え、作者名・出典込みで60文字以内に収まる候補だけを選ぶため、送信時に切り詰めません。データの出典とライセンスは [句データの出典とライセンス](poem-data-sources.md) を参照してください。
- `/seiza` は国際天文学連合が定める88星座から一つを選び、星座名の由来や表すものを短く解説します（例：`/seiza オリオン座`。名前は「座」を省略して指定でき、ラテン名や略符でも検索できます）。`/uranai` は12星座占いで、`/uranai 牡羊座` のように指定できます（星座名を省くとランダム選択）。`/omikuji` は大吉・吉・中吉・小吉・末吉・凶から運勢を選び、ひとことと今日の小さな提案を添えます。占いは娯楽向けの短い読み物です。星座データの出典は [88星座データの出典](constellation-data.md) を参照してください。

いずれも結果は一行・60文字以内で、送信・TTS はほかのチャットコマンドと同じ経路を使い、送信側の `--events-jsonl` には含めません。

これらの遊びコマンドは「コマンドパック」（データのみの小さな追加部品）で提供されています。`/dice` と `/omikuji` は標準パックとして最初から有効です。`/waka`・`/haiku`・`/seiza`・`/uranai` と、キャラ名＋必殺技を出す `/waza` は拡張パックで、`ptk --install-commands` で有効化すると使えるようになります。パックの形式が正しいかは `ptk --check-commands` で（部屋に入らずに）確認できます。自分のパックを置く場所は `~/.config/ptk/commands/` で、見つけた未有効化のパックは起動時に警告と有効化の手順を案内します。

## ボス画面と隠し要素

- ボス画面は起動ごとに一度だけ抽選され、業務画面（週次メモ・Lotus 1-2-3風ワークシート・開発進捗）のいずれかが95%、レトロゲーム風画面が約5%です。選ばれた画面はその CLI セッション中、ロビーと部屋で共通です。ロビー・部屋のどちらでも F12 で切り替わり（部屋では短時間の Esc 二回でも起動）、任意のキーで戻ります。画面を隠している間も通話・チャットは続きます（`ptk join` の行表示では利用できません）。`/boss` は部屋内コマンドではありません。検証時のみ `ptk --boss` でロビー起動直後に画面を表示できます（削除予定の一時オプション）。
- 隠しスタッフロールはロビーの部屋一覧で `↑ ↑ ↓ ↓ ← → ← → B A` を実際に押すと起動します。検索中や部屋内では起動せず、矢印キーによる通常の一覧移動も維持します。動作確認時だけ `ptk --konami` で起動直後に表示できます（削除予定の一時オプション）。出典・権利の注意点は [イースターエッグのメモ](easter-egg.md) を参照してください。

## 配信部屋

配信部屋では聞き役として入ります。配信者と、配信者が許可した人の声が聞こえます（話すことはできません）。配信者の本人確認が済むまで、配信者の音声は再生されません。仕組みは [リファレンス](reference.md#配信部屋の名簿と本人確認oath) を参照してください。
