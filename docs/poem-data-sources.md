# 句データの出典とライセンス

`/waka` と `/haiku` は、下記の一次配布元から取得した句本文だけをローカルJSONとして同梱します。**現代語訳、注釈、校訂書、外部の近現代著作物は含めていません。**アプリ本体のライセンスと、句データのライセンスは別です。

## 古今和歌集（`data/kokin-wakashu.json`）

- **出典**: 国文学研究資料館「嘉禄二年本『古今和歌集』の翻刻およびTEI/XMLデータ」
- **元データ**: [`Kokinwakashu_200003050_20240922.xml`](https://github.com/kokubunken/kokinwakashu/blob/a9bdc1b934621f5458531d974588c53515d42544/Kokinwakashu_200003050_20240922.xml)（確認したGitコミット: `a9bdc1b934621f5458531d974588c53515d42544`）
- **データ作成者**: 幾浦裕之、金子佳央、玉井楽乃、越田健介。国文学研究資料館の元リポジトリREADMEに記載された作者名です。
- **ライセンス**: [クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/)。同リポジトリREADMEは公開TEI/XMLデータをCC BY 4.0のもとで公開すると明記しています。
- **表示例**: `嘉禄二年本『古今和歌集』の翻刻およびTEI/XMLデータ、国文学研究資料館（データ作成者：幾浦裕之、金子佳央、玉井楽乃、越田健介）、CC BY 4.0`。
- **チャット内の短い出典表示**: `〔古今集・国文研〕`。完全な出典・作者・ライセンスと改変内容はこの文書に記載しています。

### 抽出・改変

`scripts/build-poem-data.py` が、上記の固定コミットにあるTEI/XMLから `div[@type="和歌"]` を読み取ります。本文は**直接の `<l>` 要素が1つだけ**ある歌に限定し、異文箇所は元XMLの `<app>` 内にある `<lem>` の本文を採用します。作者名は歌の `note type="作者名"` にある構造化作者参照を優先し、なければ `<l>` の `resp` 参照を使います。作者参照がない歌、複数行・行なしの歌、作者・出典を添えた最終メッセージが60 Unicode文字を超える歌は除外します。本文・作者参照の空白と改行は一行に整え、TEIの注記・左注・校異の別読みは本文に取り込みません。

確認したスナップショットでは、元XMLの和歌区分1,031件から987首を収録しました（4件は単一行でなく、35件は作者参照がなく、5件は60文字の送信上限を超えるため除外）。JSONの `id` は元TEIの行番号です。候補選択後の送信本文を切り詰めることはありません。

## 正岡子規の俳句（`data/shiki-haiku.json`）

- **出典**: 松山市「[正岡子規の俳句（季節別）](https://www.city.matsuyama.ehime.jp/shisei/opendata/metadata/shikihaiku.html)」。公式メタデータの公表組織名は松山市、作成者は教育委員会事務局 子規記念博物館です（ページ更新日: 2026年2月13日）。
- **元データ**: 同ページからリンクされる春・夏・秋・冬・新春・雑のUTF-8 CSV 6ファイル。ビルド時に取得したレコードは合計25,079句です。
- **ライセンス**: 松山市の当該データの表示はCC-BYです。同市[オープンデータ利用規約とCCライセンス案内](https://www.city.matsuyama.ehime.jp/shisei/opendata/top.html)は、CC-BY対象データについて[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)を示し、出典表示を求めています。市の規約例に従い、改変したデータであることも明示します。
- **表示例**: `「正岡子規の俳句（季節別）」、松山市・教育委員会事務局 子規記念博物館、CC BY 4.0（俳句欄を抽出し、JSON形式に変換）`。
- **チャット内の短い出典表示**: `〔松山市・子規俳句〕`。

### 抽出・改変

`scripts/build-poem-data.py` は6つの公式CSVから「俳句」と「季節」だけを読み取り、`id` に元ファイル名と番号を残してJSON化します。CSVの俳句本文に含まれる改行・空白は一行に整えます。空欄や、作者・出典を添えたメッセージが60 Unicode文字を超える句は除外します（確認したスナップショットでは空欄・超過とも0件）。表示する作者は元データの対象作品に基づき正岡子規です。

## ライセンス範囲の注意

国文学研究資料館のオープンデータ一覧が案内する「日本古典籍データセット」（CODH/NII）のライセンスはCC BY-SAとして説明されていますが、**このアプリはその画像・本文データセットを取り込んでいません**。本機能は別の配布物である国文学研究資料館の上記GitHub TEI/XMLリポジトリを固定コミットから利用し、そのREADMEが明記するCC BY 4.0を適用しています。別配布物のライセンス表記を混同しないでください。

## 再生成

Python 3標準ライブラリとネットワーク接続があれば、次のコマンドでJSONを再生成できます。古今集は出典コミットを固定し、松山市CSVは公式ページに現在掲載されているファイルを取得します。

```sh
python3 scripts/build-poem-data.py
```

データを更新した場合は、元ページの最新版ライセンスと利用規約、生成件数および差分を再確認してください。
