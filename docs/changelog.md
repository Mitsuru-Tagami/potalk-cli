# 更新履歴 (Changelog)

potalk-cli の変更履歴です。新しいものが上です。日付はマージ／反映日（JST）。

## 2026-10-26
- **TURN 対応**（PR #65、Issue #2 はクローズ）：自前の Cloudflare Worker（`worker/pot-turn-cli.js`）と端末別 Bearer トークンを設定すると、TURN 中継（relay のみ）で接続して相手に IP を見せない使い方ができるようになりました。未設定の場合は従来どおり STUN のみで、資格情報の取得に失敗した場合も STUN 直結にフォールバックして、その旨を画面に表示します。仕組みとセットアップは [TURN ガイド](turn.md) を参照してください。

## 2026-10-25
- 旧い招待リンクの読み替え（MOVED_ROOMS）を移植しました（PR #64）。
- Nostr リレーの設定を本家に同期しました（PR #62、Issue #53）。

## 2026-10-24
- 受け取る文字の整形を本家 PROTOCOL §7（見えない文字の除去）に揃えました（PR #59、Issue #55）。
- 大音量ガード（本家 v0.16.11〜13 相当）を追加しました（PR #60、Issue #57）。
- 本家との差異メモ `potalk-cli-vs-po-talk.md` を全面更新しました（PR #56）。

## 2026-10-23
- BOT 専用音声（PipeWire 入力）と JSONL 入退室通知に対応しました（PR #54、契約名 `potalk-bot-audio-v1`／`potalk-bot-audio-pipewire-v1`）。両 BOT の launcher は新 CLI 前提となり、旧 CLI では起動を拒否します。契約の詳細は [リファレンス](reference.md) を参照してください。


### 2026-10-14
- `ptk --mic-test` で既定のマイク入力を5秒測定し、RMS・ピークと入力レベルの目安を表示します。録音は保存せず、SoXが使える場合はローカル再生します。通話中のTUIにもCLIへ届くマイク入力メーターを追加しました。物理マイクの品質や回線品質を判定する機能ではありません。

### 2026-10-13
- ロビーと通話中のTUIのボス画面に、週次メモ・Lotus 1-2-3風ワークシート・開発進捗の3種類を追加しました。CLI起動時に画面種別を一度だけ抽選し、約5%の確率でレトロゲーム風画面を表示します。ロビー・部屋で同じ種別を使い、リサイズでは抽選し直しません。F12（部屋では短時間のEsc二回でも起動）で表示し、任意のキーで戻れます。旧 `b` ショートカットと部屋内 `/boss` コマンドは廃止し、`b` は通常入力として扱います。マウス操作は受け付けず、通話セッションは継続します。動作確認用に `ptk --boss` で起動直後に表示できます（一時フラグ）。
- 隠しスタッフロールはロビーTUIの部屋一覧で実際に `↑↑↓↓←→←→BA` とキー入力したときだけ起動し、部屋内のチャット入力・コマンドからは起動しません。動作確認用の `ptk --konami` は一時フラグです。MMLから実行時に音を合成し、音源バイナリは同梱しません。出典・権利の注意点は[イースターエッグのメモ](docs/easter-egg.md)を参照してください。
- `/cp`・`/copy` のクリップボード書き込みをNode標準の子プロセス機能とOS標準コマンドに切り替え、`clipboardy` と未使用の開発依存 `eslint` を削除しました。Linuxでは `wl-copy`・`xclip`・`xsel` を順に試します。

### 2026-10-12
- `/hbk <番号>`・`/unhbk <番号>` で相手をセッション限定のローカルミュートにできるようにしました（Issue #19）。相手への通知や通信遮断は行いません。
- `/card <番号> --verify` で、鍵応答成功後にX・GitHub・Nostrの本家SNS証拠を照合できるようにしました。確認できるのはSNSアカウントと名刺鍵の結び付きであり、人の実名や名刺本文の真偽ではありません。
- VOICEVOX / COEIROINK v2の声を選ぶだけで設定できる、対話式BYOE TTSセットアップを追加しました。話者IDやJSONの手編集は不要です。
- Windows・macOSを含むOS別の導入手順と、SoXの音声設定・トラブルシューティングを追加しました。
- 名刺を本家本番のプロトコルに合わせ、`pr` をSNS証拠オブジェクトとして扱うよう修正しました。カード本文署名やSNS本人確認を装わず、確認できない状態は未検証と表示します。

### 2026-10-11
- 部屋内コマンドを Tab で補完できるようにし、`/cp`・`/copy` で部屋URLをクリップボードへコピーできるようにしました（Issue #22、#18）。
- 本家と同じ条件で木の芽が成長し、ロビーと参加者一覧に段階バッジを表示するようにしました（Issue #25）。
- `/card` で名刺（ひとこと・SNS ID・お礼窓口）を対話編集し、本家方式の鍵応答を使って交換できるようにしました（Issue #26）。
- `ptk join` / `ptk create` の `--events-jsonl` で、相手から受信したコメントと既知参加者の入退室をJSON Linesで標準出力へ流せるようにしました。
- `--tts <コマンド>` で受信コメント本文を任意の外部TTSコマンドへ非同期で渡せるようにしました（エンジンは同梱しません）。

### 2026-10-10
- **配信部屋の安全性**: 名簿上の配信者に `oath` のチャレンジを送り、名簿で確認済みの公開鍵による署名を検証。本人確認が済むまで配信者の音声を再生しないようにしました（Issue #20）。CLI は配信部屋では聞き役として参加し、配信者用の秘密鍵署名には対応しません。
